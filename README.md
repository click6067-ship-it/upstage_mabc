# Paychecker

내 월급, 어디가 달라졌을까요?

한국어 명세서가 낯선 이주노동자를 위한 급여 확인 서비스.

정정 전·후 급여 명세서를 PDF로 올려서 비교할 수 있어요.

- 월급 못 받음
  - 받기로 한 월급이 들어오지 않았을 때
- 적거나 달라짐
  - 금액이 바뀌어서 확인하고 싶을 때
- 명세서 이해
  - 항목이 여러 개일 때 어떤 항목이 대응되는지 볼 때
- 직접 입력
  - 버튼 대신 직접 항목을 입력하고 싶을 때

입력한 내용은 이 화면에서만 잠깐 기억해요. 새로고침하면 지워질 수 있어요.

## 핵심 사용법

1. 시작 화면에서 목적을 골라요.
   - `적거나 달라짐`을 고르면 정정 전/후 명세서를 비교하는 화면으로 가요.
2. 정정 전 명세서 PDF를 올려요.
   - 업로드하면 PDF에서 추출한 초안을 보여줘요.
   - 초안을 확인한 뒤, 필요한 항목만 골라서 입력에 적용할 수 있어요.
   - 처음부터 비어 있던 행은 적용 시점에 제거되고, 이미 사용자가 작성하던 행은 남아요.
   - PDF에서 급여 기간이 추출되면 그 값이 기간 입력란에도 반영돼요.
3. 급여 기간을 입력해요.
   - 비어 있으면 양쪽 모두 같은 기간(예: 2026-08-01 ~ 2026-08-31)을 넣어요.
4. 정정 후 명세서 PDF를 올리고 같은 방식으로 적용해요.
5. 항목을 연결해요.
   - 양쪽 항목 이름이 같고 각각 하나뿐이면 비교 후보로 바로 연결해 보여줘요.
   - 애매하거나 중복이면 자동으로 확정하지 않고, 사용자가 직접 확인해요.
6. 비교를 실행해요.
   - 결과에는 요청 ID나 내부 필드명 대신 실제 항목명(예: 식대)과 금액 같은 표시를 보여줘요.
7. Solar 설명·질문을 확인해요.
   - 어떤 항목이 어떻게 바뀌었는지 설명과, 회사에 확인할 질문을 볼 수 있어요.
   - 필요하면 설명을 복사해서 써요.
8. 정정 후 값을 수정하고 다시 비교할 수 있어요.
   - 예: 식대를 70000에서 80000으로 바꾼 뒤 다시 비교해요.

## 실행 방법

### 프론트엔드

```bash
cd frontend
npm install
npm run dev
```

### 백엔드

```bash
cd backend
pip install -r requirements.txt
uvicorn backend.server:app --host 0.0.0.0 --port 8000
```

## 환경변수

이름만 적어요. 실제 값은 넣지 마세요.

- `UPSTAGE_API_KEY`
  - PDF 파싱과 Solar 호출에 사용해요.
- `PAID_FEATURES_ENABLED`
  - 설명 기능 사용 여부를 켜는 플래그예요.
  - 코드 기본값은 꺼져 있어요.

## API 엔드포인트
